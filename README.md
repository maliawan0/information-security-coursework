## Environment

Labs were run in an isolated **Kali Linux** guest on **VirtualBox** — the standard setup for this course, so that scanning and exploitation exercises stay inside a disposable VM rather than touching a host or any live network.

## Topics covered

Classical and modern cryptography · hashing and message integrity · network reconnaissance and scanning · vulnerability assessment · secure system configuration
